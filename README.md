# Brandon Munisur Portfolio — React V2 (fixed preview)

This is a standalone React + Vite portfolio. It does **not** modify the existing GitHub portfolio.

## Run it

Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Vite will print a local address, normally `http://localhost:5173/`. Open that exact address in your browser.

### Windows shortcut
You can also double-click `START_PORTFOLIO.bat`.

## If something goes wrong
This version includes an Error Boundary. A React rendering failure should now display a readable error on the page instead of leaving you with a blank screen.

## Production test

```bash
npm run build
npm run preview
```

## What is included
- Reusable React components
- Full Stack Engineer positioning
- Animated hero and role ticker
- Project cards and interactions
- Responsive layout
- Live public GitHub API repository feed with fallback data
- About and contact sections
- Reduced-motion accessibility support
